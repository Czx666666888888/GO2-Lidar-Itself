# Go2 真机操作流程

从开机到键盘控制、记录数据、安全下电的完整步骤。

---

## 0. 前置准备（一次性）

### 0.1 狗侧
1. 给 Go2 上电，进入 **Wi-Fi 模式**
2. 手机 Unitree App 查看狗 IP：`Device → Data → Automatic Machine Inspection → STA Network: wlan0`
3. **关闭手机 App 连接**（WebRTC 单连接，App 占用时电脑连不上）
4. 电脑和狗处于**同一局域网**

### 0.2 电脑侧（只需一次）
1. 编译遥控包：
   ```bash
   cd /home/lch/dog/go2_ws
   colcon build --packages-select go2_keyboard_teleop
   ```
2. **（仅新固件 ≥ 1.1.15）** 获取狗的 AES key：
   ```bash
   pip install unitree_webrtc_connect
   unitree-fetch-aes-key --email 你的邮箱 --password '你的密码' --device-type Go2
   ```
   记下 32 位 hex 字符的 key（按序列号对应你的狗）。旧固件可跳过此步。

## 1. 环境准备（每个终端都执行）

```bash
cd /home/lch/dog/go2_ws && source install/setup.bash
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp ROS_LOCALHOST_ONLY=1 ROS_DOMAIN_ID=86
```

> 所有终端用**相同的 `ROS_DOMAIN_ID`**。

---

## 2. 连接狗（终端 1）

```bash
cd /home/lch/dog/go2_ws && source install/setup.bash
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp ROS_LOCALHOST_ONLY=1 ROS_DOMAIN_ID=86

# 老固件(无 AES key)
ROBOT_IP=192.168.xxx.xxx CONN_TYPE=webrtc ros2 launch go2_robot_sdk robot.launch.py

# 新固件(≥1.1.15, 需 AES key)
ROBOT_IP=192.168.xxx.xxx ROBOT_AES_KEY=<32位hex> CONN_TYPE=webrtc \
  ros2 launch go2_robot_sdk robot.launch.py
```

**连接成功标志**：日志无 `Failed to complete encrypted handshake` 报错，且能收到数据。

---

## 3. 键盘遥控（终端 2）

```bash
cd /home/lch/dog/go2_ws && source install/setup.bash
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp ROS_LOCALHOST_ONLY=1 ROS_DOMAIN_ID=86
ros2 run go2_keyboard_teleop go2_keyboard_teleop_node
```

启动后看到 `已进入键盘读取模式 (fd=0, isatty=True)`，即可按键。

| 按键 | 动作 | 速度 |
|---|---|---|
| `w`/`s` | 前进/后退 | ±0.3 m/s |
| `a`/`d` | 左移/右移 | ±0.2 m/s |
| `q`/`e` | 左转/右转 | ±0.4 rad/s |
| `空格` | 急停 | 全零 |
| `x` | 退出 | — |

按住满速、松手约 300ms 停止。

## 5. 记录 IMU + 激光雷达（终端 4，可选）

```bash
cd /home/lch/dog/go2_ws && source install/setup.bash
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp ROS_LOCALHOST_ONLY=1 ROS_DOMAIN_ID=86
ros2 run go2_keyboard_teleop go2_sensor_recorder --ros-args -p outdir:=/home/lch/dog/go2_data
```

- 控制完成后按 **Ctrl-C** 保存
- 或定时自动保存：追加 `-p duration:=60.0`（60 秒自动停止）

---

## 6. 停止流程

1. 键盘终端：按 `x` 退出（先清零速度）
2. 记录终端：`Ctrl-C` 保存数据
3. 驱动终端：`Ctrl-C` 断开连接
4. 确认狗停稳后，再关闭狗电源

---

## 7. 数据取回

记录的数据在 `outdir`（默认 `/home/lch/dog/go2_data`）：

| 文件 | 内容 |
|---|---|
| `imu.csv` | 时间戳、线加速度、角速度、四元数 |
| `lidar.npz` | 点云坐标 + 每点时间戳 + 反射强度 |

## 8. 安全注意事项

1. **首次控制先慢速**：`--ros-args -p max_vx:=0.15 -p max_vyaw:=0.2`
2. 保持狗在**平坦开阔**场地，周围留 ≥2m 空间
3. **急停**用空格键，紧急时直接按狗的急停按钮
4. 控制时注意狗电量，低电量先停止

---

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| `Failed to complete encrypted handshake` | 新固件需设 `ROBOT_AES_KEY`（见 0.2） |
| 连不上狗 | 确认同网段、手机 App 已关闭、`ROBOT_IP` 正确 |
| 键盘按键无反应 | 确认 `isatty=True`、小写按键、终端有焦点 |
| 收不到数据 | 确认驱动已连上、`ROS_DOMAIN_ID` 一致 |
| 狗不动 | 狗已上电且站立、驱动日志无报错、速度参数 > 0 |
