# go2_keyboard_teleop 完整使用指南

纯键盘控制 Unitree Go2，支持：键盘遥控（长按运行/松手停止）、指令监视、IMU+激光雷达数据记录。
**只发布 `Twist` 速度指令，不含任何路径规划/建图。**

---

## 一、环境准备（每个终端都要执行）

```bash
cd /home/lch/dog/go2_ws && source install/setup.bash
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp ROS_LOCALHOST_ONLY=1 ROS_DOMAIN_ID=86
```

> 所有终端必须使用**相同的 `ROS_DOMAIN_ID`**，否则节点间无法通信。

## 二、首次编译（只需一次）

```bash
cd /home/lch/dog/go2_ws
colcon build --packages-select go2_keyboard_teleop
source install/setup.bash
```

## 三、真机完整流程（控制 + 监视 + 记录）

### 终端 1：连接狗（WebRTC 驱动）

```bash
cd /home/lch/dog/go2_ws && source install/setup.bash
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp ROS_LOCALHOST_ONLY=1 ROS_DOMAIN_ID=86
ROBOT_IP=<狗IP地址> ros2 launch go2_robot_sdk robot.launch.py
```

> `<狗IP地址>` 换成 Go2 的实际 IP（同一局域网内，如 `192.168.123.161`）。

### 终端 2：键盘遥控

```bash

export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp ROS_LOCALHOST_ONLY=1 ROS_DOMAIN_ID=86
ros2 run go2_keyboard_teleop go2_keyboard_teleop_node
```

按键后立即看到 `>>> 下发到狗: vx=+0.30 ...`。

### 终端 3（可选）：实时监视下发指令

```bash
cd /home/lch/dog/go2_ws && source install/setup.bash
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp ROS_LOCALHOST_ONLY=1 ROS_DOMAIN_ID=86
ros2 run go2_keyboard_teleop go2_cmd_monitor
```

### 终端 4（可选）：记录 IMU + 激光雷达

```bash

export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp ROS_LOCALHOST_ONLY=1 ROS_DOMAIN_ID=86

#   ... -p outdir:=/home/lch/dog/go2_data -p duration:=60.0
```

## 四、按键映射（长按运行 / 松手停止）

| 按键 | 动作 | 速度字段 |
|---|---|---|
| `w` / `s` | 前进 / 后退 | `linear.x = ±0.3` |
| `a` / `d` | 左移 / 右移 | `linear.y = ±0.2` |
| `q` / `e` | 左转 / 右转 | `angular.z = ±0.4` |
| `空格` | 急停 | 全零 |
| `x` / `Ctrl-C` | 退出（先清零） | — |

- **按住即满速运行，松开约 300ms 后自动停止**
- 支持组合键（如 `w`+`e` = 前进 + 右转）

## 五、参数说明

### 键盘节点 `go2_keyboard_teleop_node`

| 参数 | 默认 | 说明 |
|---|---|---|
| `max_vx` | 0.3 | 前进/后退最大速度 (m/s) |
| `max_vy` | 0.2 | 平移最大速度 (m/s) |
| `max_vyaw` | 0.4 | 转向最大角速度 (rad/s) |
| `publish_rate` | 20.0 | 发布频率 (Hz) |
| `topic_cmd_vel_out` | `cmd_vel_out` | 下发到驱动的速度话题 |
| `topic_cmd_vel` | `cmd_vel` | 调试用标准话题 |

改速度示例：
```bash
ros2 run go2_keyboard_teleop go2_keyboard_teleop_node \
  --ros-args -p max_vx:=0.15 -p max_vyaw:=0.2
```

### 监视器 `go2_cmd_monitor`

| 参数 | 默认 | 说明 |
|---|---|---|
| `topic` | `cmd_vel_out` | 监听的下发指令话题 |

### 记录器 `go2_sensor_recorder`

| 参数 | 默认 | 说明 |
|---|---|---|
| `outdir` | `~/go2_data` | 数据保存目录 |
| `imu_topic` | `imu` | IMU 话题 |
| `lidar_topic` | `point_cloud2` | 激光雷达话题 |
| `duration` | 0.0 | >0 则定时自动保存退出（秒） |

## 七、数据产物

| 文件 | 内容 |
|---|---|
| `imu.csv` | 表头 + 每行：`sec,nanosec,线加速度xyz,角速度xyz,四元数xyzw` |
| `lidar.npz` | `points`(N,3) 点云坐标、`timestamps`(N,) 每点时间戳、`intensity`(N,) 反射强度 |

用 numpy 读取：
```python
import numpy as np
d = np.load("lidar.npz")
xyz = d["points"]; ts = d["timestamps"]; i = d["intensity"]
```

## 八、节点总览

| 节点 | 功能 | 关键话题 |
|---|---|---|
| `go2_keyboard_teleop_node` | 键盘遥控 | 发布 `cmd_vel_out` + `cmd_vel` |
| `go2_cmd_monitor` | 指令监视 | 订阅 `cmd_vel_out` |
| `go2_sensor_recorder` | 数据记录 | 订阅 `imu` + `point_cloud2` |

## 九、常见问题

- **收不到数据**：确认 `go2_driver_node`（robot.launch）已启动、`ROS_DOMAIN_ID` 一致、激光雷达话题用 best_effort。
- **Ctrl-C 不保存**：conda 环境建议用 `duration` 定时停止，或直接按 `x`/Ctrl-C（已做标志位兼容）。
- **狗不动**：确认狗已上电、`ROBOT_IP` 正确、与电脑同网段、驱动日志无连接报错。
