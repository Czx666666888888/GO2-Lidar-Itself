# GO2 最小规则避障（PC）

唯一 PC 测试入口：在仓库根目录使用 `bash go2_test.sh --mode avoid`。
内部 `avoid_ws/run.sh` 由该入口调用。默认仅离线检查，不运动。

```bash
cd /home/czx666/today_full_20260901/today_full
# 离线测试
bash go2_test.sh --mode avoid --dry-run
# 只读观察 10 秒，先用静止障碍核对前/左/右的 0、1 是否符合现场
bash go2_test.sh --mode avoid --observe
# 现场确认站立、平地空旷、物理急停可用且其他运动控制已结束后，由操作者执行
bash go2_test.sh --mode avoid --execute
# Ctrl+C 停止；也可以在另一终端执行
bash go2_test.sh --mode avoid --stop
```

## 条件与动作

读取原生 `/utlidar/cloud`，转换到机身坐标，过滤已有的有限机身自反射区域。
点高 0.10–1.20 m 且位于机身外的点作为障碍候选。
固定检测框内有候选点就是 `1`，没有就是 `0`，日志每秒输出前、右、左、后状态。
检测框和阈值统一在 `go2_reactive_avoid/lidar.py`、`controller.py`。

按以下优先级执行：

| 条件 | 动作 |
|---|---|
| 前=0，左=0，右=0 | 固定 0.20 m/s 直走探索 |
| 前=1，右=0 | 立即发零速，反馈停稳后右转 90° |
| 前=1，右=1，左=0 | 立即发零速，反馈停稳后左转 90° |
| 前=1，右=1，左=1 | 停稳后向右分两段各转 90°；每段停稳；掉头后前仍=1 则结束本轮 |
| 前=0，仅左=1 | 以 0.20 m/s 向右走 20°弧线，随后接续直行 |
| 前=0，仅右=1 | 以 0.20 m/s 向左走 20°弧线，随后接续直行 |
| 前=0，左=1，右=1 | 保持直走，不左右反复摆动 |

前向检测：距机身前缘 **25 cm** 内、机身中心线左右各 33 cm。
侧向检测：距机身侧边 **15 cm** 内、机身中心前后各 55 cm。
后向 55 cm 仅显示，不参与选动作。不倒车。
同一次侧边触发只修正一次，两侧都恢复 0 后才允许再次触发。
弧线期间前方变 1 立即停车；90°原地转动期间按反馈完成转角，再重新判断前方。

转角使用 `/lf/sportmodestate` 航向反馈，容差 ±3°。
90°每段最长 10 秒，20°最长 5 秒；原地角速度上限 0.60 rad/s，弧线 0.50 rad/s。
停车确认需线速度 <0.035 m/s、角速度 <0.08 rad/s 持续至少 0.25 秒，且扫描/反馈已经更新。

## 保留的运行保护与边界

不再计算地面覆盖、分区覆盖、机身净空或旋转扫掠，也不按障碍距离连续调速。
空点云或全无效点云不可用；雷达/Sport 数据超过 0.40 秒、姿态/航向异常、反馈错误码变化、
控制权丢失、其他控制程序发 Sport 请求时停车退出。每轮运动最长 90 秒。
运动仍经现有 Sport gate 和 lease 唯一出口；首次使用需已有人工核实的本机
`avoid_ws/sport_writers.local`，该文件不提交 Git。每次执行前只读复核机载端点。

`0` 仅表示本帧检测框里没有回波候选，**不证明物理空间可通行**。
取消覆盖和扫掠判断后，盲区、低矮障碍、悬空台阶及转身碰撞不会由这些规则识别。
有限自反射过滤区域内的外物也可能被滤除；需要操作者现场监护。

网卡默认 `enp12s0`，可用 `GO2_IFACE` 指定。
估计站立雷达高度默认 0.30 m，可用 `GO2_AVOID_LIDAR_HEIGHT=实测米数` 调整。
运行日志保存在 `avoid_ws/log/run.*/`，退出/急停路径由原入口处理。
不启动 SLAM、FAR、相机识别或 S1 抓取。
