# GO2 独立自主导航往返测试

在仓库根目录执行。默认网卡为 `enp12s0`，可用 `GO2_IFACE` 指定有线网卡。复用 `deploy_ws/install` 中已有的 ROS 包和路径模板。独立的 pathFollower 首次编译到 `tmp/navigation_test/follower`。

| 操作 | 命令 |
|---|---|
| 离线构建、回归及启动配置解析 | `bash go2_nav_test.sh --dry-run` |
| 真机单轮往返，狗已站稳、路线空旷且操作员手持急停时使用 | `bash go2_nav_test.sh --execute` |
| 另一个终端提前返航 | `bash go2_nav_test.sh --return` |
| 另一个终端请求独立安全门停车 | `bash go2_nav_test.sh --stop` |

探索节点用机身中心里程计记录起点，地图就绪后等待 2 秒，再优先从前方可达自由区域选观察点。到达首个观察点的 0.25 m 范围就返航。探索 30 秒未到点也转入返航。按约 0.30 m 间距记录的航点倒序送给局部规划器，起点容差为 0.15 m。进场深度取决于现场地图和实际到达的目标。输出和日志目录见终端打印的 `tmp/navigation_test/run.*/`。

`DONE` 表示里程计先进入观察点容差，再进入起点容差并请求停车。提前返回起点记录 `RETURNED_EARLY`。返航目标连续 15 秒没有至少 0.10 m 进展会锁存 `RETURN_BLOCKED`。就绪等待上限为 60 秒，全程上限为 180 秒。急停或故障后结束本轮。软件结果与现场实际位移和停车分别验收。

## 代码来源及堵点

来源为用户提供的 `go2_nav_current_20261118_1408.tar.gz`，SHA256 为 `1be07fad9031b736f5eb875302df17428d31d7933fd4f36ad0ffb74943f96feb`。采用包内 Point-LIO、terrain、FAR、局部规划配置和跟踪器，移植 NBV、障碍记忆及前停逻辑。安全门继承本仓库的 Sport lease 和心跳互锁。

- 现有 full 的独立 localPlanner 声明缺少 `pathFolder`。源码会从该目录读取路径模板。此测试走带模板目录的局部规划 launch。
- 包内返航受阻时，FAR 和探索节点可以同时发布 `/way_point`。测试中 FAR 发到专用话题，探索节点在去程转发 FAR 航点、在回程直接发送记录点。两程都经过局部避障。
- 原始 NBV 用雷达位置判到点。下游规划用机身中心，0.30 m 参考点偏置超过 0.15 m 返航容差。测试统一用 `/base_state_estimation`。
- 原包逐点删除过滤结果并将第 5 个字段强制转整数。测试按字段名称变换坐标并批量过滤，保留环号和点时间的类型。雷达和 IMU 订阅保留本仓库的 sensor-data QoS。
- 原包启动脚本有固定休眠、外机绝对路径及无时限的 topic pub。此入口并行启动节点，通过定位、地形、局部路径、任务心跳、Sport 状态和 lease 判断就绪。
- 包内 README 记录过数据流同时中断约 6.7 秒和长跑定位漂移。具体根因未获独立复现。障碍记忆可保留历史障碍，里程计漂移或机身点误入图仍可能封住通道。
